راهنمای راه‌اندازی «غربالگری روان‌شناختی شخصیتی» روی Vercel
==========================================================

این نسخه دیگر برای داده‌های اصلی از localStorage استفاده نمی‌کند. پرسشنامه‌ها، تصاویر سوال‌ها و پاسخ‌ها از طریق API در فایل JSON مخزن خصوصی GitHub ذخیره می‌شوند و همه‌ی دستگاه‌ها از همان منبع مشترک استفاده می‌کنند.

۱) ساخت مخزن خصوصی برای داده‌ها
-------------------------------
- به https://github.com/new برو.
- نام مخزن را soundstudent-data بگذار.
- Private را انتخاب کن.
- گزینه‌ی Add a README file را فعال کن تا شاخه‌ی main ایجاد شود.
- مخزن را بساز.

از مخزن عمومی سایت برای ذخیره‌ی پاسخ‌های شخصی استفاده نکن؛ مخزن داده باید Private باشد.

۲) ساخت Fine-grained token
--------------------------
- به https://github.com/settings/personal-access-tokens/new برو.
- Token name را مثلاً soundstudent-vercel-data بگذار.
- Expiration را انتخاب کن.
- Repository access را روی Only select repositories بگذار و soundstudent-data را انتخاب کن.
- در Permissions، روی Add permissions کلیک کن.
- در فهرست Repository permissions، مورد Contents را پیدا و Read and write را انتخاب کن.
- توکن را Generate کن و فقط در تنظیمات Vercel قرار بده؛ آن را داخل کد یا چت قرار نده.

اگر Repository permissions یا Add permissions را نمی‌بینی، مطمئن شو در صفحه‌ی Fine-grained personal access token هستی، نه صفحه‌ی توکن Classic. اگر مورد Contents دیده نمی‌شود، از بالای فرم صفحه‌ی ایجاد توکن را دوباره باز کن و بخش Permissions را باز/گسترش بده.

۳) تنظیم Vercel
----------------
در پروژه‌ی Vercel سایت برو به Settings > Environment Variables و این متغیرها را اضافه کن:

GITHUB_OWNER = mamadzzz123
GITHUB_REPO = soundstudent-data
GITHUB_BRANCH = main
GITHUB_TOKEN = توکن Fine-grained ساخته‌شده
ADMIN_PASSWORD = salamfarmande123

GITHUB_DATA_PATH اختیاری است و نیاز به تنظیم ندارد؛ مقدار پیش‌فرض آن data/psy-screening.json است.

پس از ذخیره‌ی متغیرها، از Deployments یک Redeploy انجام بده.

۴) آزمون
---------
این مسیر را باز کن:
https://آدرس-سایت-تو.vercel.app/api/health

پاسخ مورد انتظار شامل این موارد است:
- "ok": true
- "missing": []
- "repositoryAccessible": true

این مسیر وجود متغیرها و دسترسی به مخزن را بررسی می‌کند. برای اطمینان از مجوز نوشتن، از پنل مدیریت یک پرسشنامه‌ی آزمایشی منتشر کن؛ اگر GitHub پیام داد که مجوز کافی نیست، Contents را روی Read and write بگذار.

مسیر https://آدرس-سایت-تو.vercel.app/api/surveys باید در شروع، فهرستی خالی یا فهرست پرسشنامه‌های منتشرشده را برگرداند. پاسخ‌های اشخاص در خروجی عمومی API نمایش داده نمی‌شوند؛ پاسخ‌ها از مسیر مدیریت پس از ورود مدیر دیده می‌شوند.

۵) انتقال اطلاعات نسخه‌ی قبلی
-----------------------------
اگر پرسشنامه‌هایی در localStorage همین مرورگری که مدیر با آن وارد می‌شود باقی مانده باشد و مخزن مشترک هنوز پرسشنامه‌ای نداشته باشد، پس از ورود موفق مدیر درباره‌ی انتقال اطلاعات قدیمی سوال می‌شود. تأیید آن، پرسشنامه‌ها و پاسخ‌های موجود را یک‌بار به مخزن مشترک منتقل می‌کند. اطلاعات قدیمی تا زمان تأیید حذف نمی‌شود.

نکات
----
- رمز مدیریت از متغیر ADMIN_PASSWORD خوانده می‌شود؛ آن را در تنظیمات Vercel تغییر بده تا رمز دلخواهت شود.
- تصویر سوال‌ها پیش از ارسال کوچک می‌شود تا درخواست‌های Vercel بیش از حد بزرگ نشوند.
- این نسخه برای استفاده‌ی سبک/مدرسه‌ای از JSON ذخیره‌شده در GitHub طراحی شده است. با رشد زیاد تعداد پاسخ‌ها یا تصاویر، پایگاه داده و ذخیره‌سازی فایل جداگانه مناسب‌تر خواهد بود.
